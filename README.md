# Clockwork City

Clockwork City is an original, GTA-inspired 3D open-world action prototype for Unity 6 URP.

## Status

This repository currently contains the initial project scaffold. Open it as a Unity 6 project and follow the setup steps below.

## Unity setup

1. Install Unity 6 with 3D URP support.
2. Open this repository folder in Unity Hub.
3. Create a scene named `ClockworkCity` in `Assets/Scenes`.
4. Add a URP renderer and ground plane for testing.

## Planned vertical-slice systems

- Third-person player movement and camera
- Shooting, enemies, and health
- Enterable vehicles and driving
- Five-level wanted system
- One complete mission
- Original low-poly city environment
